# Двойной маятник: интерактивная версия PyQt6

## Установка и запуск

Python 3.10+ (рекомендуется 3.11 или 3.12). Из корня проекта:

```bash
python -m pip install -r requirements.txt
python main.py
```

Интерфейс реализован на **PyQt6**, графики на **pyqtgraph**. Matplotlib не используется в приложении. В унаследованном `run_checks.py` Matplotlib по-прежнему используется исключительно для создания диагностических изображений при тестировании; при необходимости установите его отдельно: `pip install matplotlib`.

## Работа с программой

- Слева задайте массы, длины, g, трение в опоре и шарнире, начальные углы и угловые скорости, шаг RK4. До первого запуска или после «Стоп / сброс» можно тянуть грузы мышью.
- Для стабилизации верхнего равновесия (180°, 180°) включите PID. «Подобрать PD по полюсам» вычисляет P/D коэффициенты для текущих параметров по линеаризации в верхней точке. Это **не LQR**. Параметр Ki задаётся отдельно; значение 0 превращает PID в PD, и для демонстрации устойчивости его допустимо оставить 0. Для проверки ненулевой интегральной составляющей установите небольшое Ki и проверьте поведение.
- «Старт» запускает и возобновляет, «Пауза» останавливает время, «Стоп / сброс» обнуляет историю и применяет новые начальные параметры. Во время паузы начальные условия не редактируют уже накопленную траекторию: для применения новых условий сначала нажмите «Стоп / сброс».
- «Save to PNG» сохраняет снимок центральной части окна, «Save to CSV» сохраняет **всю** накопленную историю с временем, углами (радианы), угловыми скоростями, управляющим моментом и полной энергией.
- Симуляция не имеет конечного `t_max`: `QTimer` периодически вызывает собственный шаг RK4. История сохраняется в памяти для CSV, поэтому при очень длительном запуске расход оперативной памяти будет расти. Графики прореживаются для скорости отображения.

## Математика

Состояние `x=[theta1, omega1, theta2, omega2]`; углы от вертикали вниз, поэтому верхнее положение — `(pi, 0, pi, 0)`. Уравнения Лагранжа и энергии описаны в `DERIVATION.md`. Трение в опоре `c1` и в шарнире `c2`. Момент `tau` действует в верхней опоре через `Q1` в `physics.derivatives`.

Регулятор использует один момент на оба звена:

`tau = clip(-P1*e1 - D1*omega1 - P2*e2 - D2*omega2 - Ki*integral(e1), -limit, limit)`.

Ошибки `e1,e2` — кратчайшие угловые отклонения от pi. При насыщении предусмотрено ограничение интегратора. Коэффициенты PD рассчитываются через размещение полюсов матрицы, полученной численным дифференцированием нелинейной модели в верхнем равновесии. Метод не гарантирует захват маятника из произвольных начальных положений и не является swing-up контроллером.

## Проверки

```bash
python -m unittest test_pid.py
python run_checks.py  # дополнительно нужен matplotlib; создаёт изображения в figures/
```

Проверка энергии для идеальной системы имеет смысл при `c1=c2=0` и выключенном PID. При трении и внешнем моменте полная механическая энергия **не обязана сохраняться**.

## Ограничения

- Проверено численно для малых возмущений около верхнего равновесия, а не для произвольного перевёрнутого или хаотического движения.
- В официальном ТЗ одновременно указаны PID и LQR; в соответствии с последней правкой преподавателя реализован PID, **LQR отсутствует**. Это остаётся формальным расхождением с письменным ТЗ.
- Текст `DERIVATION.md` исходного проекта включает линеаризацию нижнего равновесия; для верхнего равновесия добавлен `controller.upper_linearization` и его численная проверка.
